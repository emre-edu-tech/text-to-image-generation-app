# Step 01 — Project Scaffolding

## Goal
Set up the Flask app factory, folder structure, Tailwind build, and the
two entry points (`app.py` for local dev, `wsgi.py` for Passenger). No
image-generation logic yet — that's Step 02.

## 1. Folder structure
Create exactly this layout, directly in the project root (do not wrap it
in a parent folder — the agent is already working inside the project's
own root directory):
```
app/
├── __init__.py
├── config.py
├── main/
│   ├── __init__.py
│   └── routes.py
├── templates/
│   └── base.html
└── static/
    ├── src/
    │   └── input.css
    ├── dist/
    │   └── output.css   (generated by npm build, then committed)
    ├── js/
    └── generated_images/   (created at runtime, gitignored)
.env.example
.gitignore
requirements.txt
package.json
tailwind.config.js
app.py
wsgi.py
```

## 2. Python environment
- Create and activate a venv.
- `requirements.txt`:
  ```
  Flask
  requests
  python-dotenv
  ```
- `pip install -r requirements.txt`

## 3. Config (`app/config.py`)
```python
import os

class Config:
    SECRET_KEY = os.environ["SECRET_KEY"]
    APP_USERNAME = os.environ["APP_USERNAME"]
    APP_PASSWORD = os.environ["APP_PASSWORD"]
    CF_ACCOUNT_ID = os.environ["CF_ACCOUNT_ID"]
    CF_API_TOKEN = os.environ["CF_API_TOKEN"]
    SESSION_COOKIE_SECURE = os.environ.get("FLASK_ENV") != "development"
    PERMANENT_SESSION_LIFETIME = 60 * 60 * 24 * 7  # 7 days
```
Let it raise `KeyError` if a required var is missing — better to crash at
startup than silently run without auth or without Cloudflare credentials.

## 4. App factory (`app/__init__.py`)
```python
from flask import Flask
from dotenv import load_dotenv

load_dotenv()

def create_app():
    app = Flask(__name__)
    app.config.from_object("app.config.Config")

    from app.main import main_bp
    app.register_blueprint(main_bp)

    return app
```

## 5. Blueprint stub (`app/main/__init__.py`)
```python
from flask import Blueprint

main_bp = Blueprint("main", __name__)

from app.main import routes  # noqa: E402,F401
```
Leave `app/main/routes.py` with just a placeholder index route for now —
Step 02 fills it in properly:
```python
from app.main import main_bp

@main_bp.route("/")
def index():
    return "Scaffolding OK"
```

## 6. Entry points
`app.py` (local dev):
```python
from app import create_app

app = create_app()

if __name__ == "__main__":
    app.run(debug=True)
```
`wsgi.py` (Passenger):
```python
from app import create_app

application = create_app()
```

## 7. Tailwind v3 (npm build)
- `package.json` + `npm install -D tailwindcss@3`
- `tailwind.config.js` with:
  `content: ["./app/templates/**/*.html", "./app/static/js/**/*.js"]`
- `app/static/src/input.css`:
  ```css
  @tailwind base;
  @tailwind components;
  @tailwind utilities;
  ```
- Build script in `package.json`:
  ```json
  "scripts": { "build:css": "tailwindcss -i ./app/static/src/input.css -o ./app/static/dist/output.css --minify" }
  ```
- Run `npm run build:css` once so `output.css` exists.
- **Important:** `app/static/dist/output.css` must be committed to git —
  do not add it or the `dist/` folder to `.gitignore`. The production
  server does not run an npm build step, so this compiled file is the
  only way Tailwind styles reach the deployed app.

## 8. `.env.example` (commit this; never commit the real `.env`)
```
CF_ACCOUNT_ID=
CF_API_TOKEN=
APP_USERNAME=
APP_PASSWORD=
SECRET_KEY=
FLASK_ENV=development
```

## 9. `.gitignore`
```
.env
__pycache__/
venv/
node_modules/
app/static/generated_images/*
!app/static/generated_images/.gitkeep
```
(Keep the folder in git via a `.gitkeep`, ignore what gets generated into it.)
Note that `app/static/dist/` is deliberately absent from this list — see
the Tailwind section above, it must stay tracked in git.

## Acceptance check
- `python app.py` runs; `/` returns "Scaffolding OK"
- `output.css` exists and is committed
- `.env` does not show up in `git status`
